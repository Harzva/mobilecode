# MobileCode v0.1.72

This patch preserves the MobileCore local multimodal integration delivered in v0.1.71 and closes a version-consistency defect found during installed-release QA.

## Highlights

- Use one in-app version definition for the home screen, release link, and update service.
- Align package metadata, GitHub Pages update feed, release links, and Android asset naming on `0.1.72+62`.
- Reject release APKs whose manifest version and embedded Flutter AOT release label do not match, preventing stale incremental-build payloads from being published.
- Preserve model discovery, modality reporting, projector pairing, local model switching, and local image request support from v0.1.71.
